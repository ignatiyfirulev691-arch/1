# Weather Cities Task

Решение тестового задания на Python без внешних пакетов.

## Что делает программа

1. Загружает список городов из `Cities.txt`.
2. Для каждого города запрашивает `https://wttr.in/{City}?format=j1`.
3. Создаёт модель `WeatherData` с полями:
   - город;
   - текущая температура в °C;
   - страна.
4. Выводит текущую погоду по каждому городу.
5. Группирует данные по странам и выводит:
   - количество городов;
   - среднюю текущую температуру;
   - минимальную температуру;
   - максимальную температуру.

Используется только стандартная библиотека Python: `json`, `urllib`, `dataclasses`, `statistics`, `pathlib`.

## Запуск

Требуется Python 3.10+.

```powershell
python main.py
```

## Пример формата вывода

```text
Weather by city
---------------
Moscow, Russia: +8 °C
...

Summary by country
------------------
Russia - 5 cities, avg: +8.4 °C, min: +4 °C, max: +13 °C
```

Фактические значения вычисляются программой из текущих данных wttr.in.
